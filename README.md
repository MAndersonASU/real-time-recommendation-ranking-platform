# Real-Time Personalized Recommendation & Ranking Platform

Research engineering project combining offline batch machine learning with
real-time event streaming for personalized content recommendation and
ranking, built on the Microsoft News Dataset (MIND).

See [`docs/research-scenario.md`](docs/research-scenario.md) for the
research objective, questions, and evaluation boundaries. Architecture
documentation will be added as the system is built (`docs/architecture.md`).

## Status

Early stage: research framing and repository scaffolding are in place;
data ingestion, modeling, and serving components are not yet implemented.
